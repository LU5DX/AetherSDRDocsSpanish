# Reportar un problema

Use esta página para informar directamente a los desarrolladores sobre un error en AetherSDR. El comando **File an Issue** abre su navegador predeterminado en el rastreador de problemas de AetherSDR para que pueda describir el problema que encontró.

## Antes de comenzar

- Una conexión a internet en funcionamiento.
- Se requiere una cuenta de GitHub para enviar un problema.

## Pasos

1. Abra el menú **Help**.
2. Seleccione **File an Issue...**.

Su navegador web predeterminado abrirá el rastreador de problemas de AetherSDR. Complete la plantilla del problema con la mayor cantidad de detalles posible: qué estaba haciendo, qué esperaba que sucediera y qué vio en su lugar.

## Consejos

- El comando **File an Issue** se agregó en la versión v26.8.4. En compilaciones anteriores, el informe de errores solo estaba disponible a través del cuadro de diálogo **Support**.
- Antes de enviarlo, revise el rastreador de problemas para ver si ya existe un informe sobre el mismo problema. Comente en él en lugar de abrir un duplicado.
