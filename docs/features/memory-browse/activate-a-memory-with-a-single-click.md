# Activar una memoria con un solo clic

Active una memoria almacenada en el slice sintonizado haciendo clic en ella en el panel Memory Browser. Esto le permite saltar rápidamente a una frecuencia guardada sin escribir ni navegar por menús.

## Antes de comenzar

- Su radio debe estar conectada y encendida.
- Al menos una memoria debe estar almacenada en la radio. Si no existen memorias, el panel Memory Browser muestra "No memories are available yet."

## Pasos

1. Abra el panel Memory Browser. Aparece como un panel lateral en el divisor de la ventana principal cuando la exploración de memorias está habilitada.
2. Localice la memoria que desea activar en la tabla. Las memorias están ordenadas por frecuencia.
3. Haga clic en la fila de esa memoria.

El slice sintonizado cambia inmediatamente a la frecuencia de la memoria. La memoria más cercana a la frecuencia actual se resalta con un color de fondo distintivo.

## Función de cada control

| Control | Comportamiento | Notas |
|---|---|---|
| Memory table | Muestra cada memoria ordenada por frecuencia; un clic o Enter activa el slice sintonizado en esa memoria | Columnas: Frequency, Name. La memoria más cercana a la sintonía actual se resalta con un fondo distintivo. Un doble clic también sintoniza. |
| Highlighted row | La memoria más cercana a la sintonía actual tiene un color de fondo distintivo | Se actualiza automáticamente mientras sintoniza |
| Add Memory | Guarda el slice actual de este panadapter como una memoria | Se agrega en la parte superior del panel, encima de la lista de memorias. Se insertó en la parte superior del diseño del panel en v26.7.4. |
| No memories are available yet. | Se muestra cuando la radio no tiene memorias cargadas | |

## Consejos

- Un doble clic en una fila de memoria también la activa.
- Presione Enter mientras una fila está resaltada para activar esa memoria.
- El panel tiene un tamaño fijo de 252×460 píxeles.
