# Agregar una memoria desde el slice activo usando el botón del panel

Guarde el slice activo actual como una entrada de memoria en la lista de la radio para poder recuperarlo más adelante.

## Antes de comenzar

- Debe haber una radio conectada.
- El panel del Explorador de Memorias (Memory Browser) debe estar visible en el panel lateral de la Ventana Principal (MainWindow).

## Pasos

1. Sintonice el slice activo en la frecuencia y modo que desea guardar.
2. En el panel del Explorador de Memorias (Memory Browser), haga clic en **Add Memory**.

La frecuencia y el nombre del slice se guardan como una nueva entrada de memoria, que aparece inmediatamente en la tabla de memorias.

## Función de cada control

| Control | Comportamiento |
|---------|----------------|
| **Memory table** | Muestra cada memoria ordenada por frecuencia; un solo clic o Enter activa el slice sintonizado en esa memoria. Columnas: Frecuencia (Frequency), Nombre (Name). La memoria más cercana a la sintonía actual se resalta con un fondo distintivo. El doble clic también sintoniza. |
| **Add Memory** | Guarda el slice actual como una nueva entrada de memoria. Siempre visible en la parte inferior del panel, anclado fuera de la tabla desplazable. Información sobre herramientas: "Guarde el slice actual en este panadapter como memoria." |
| **No memories are available yet.** | Se muestra cuando la radio no tiene memorias cargadas. |

## Consejos

- La memoria se almacena en la propia radio, no localmente: el nombre y la frecuencia provienen de la configuración actual del slice activo.
