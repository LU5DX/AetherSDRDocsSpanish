# Añadir una memoria desde el slice activo usando el botón del panel

Guarde el slice activo actual como una entrada de memoria en la lista de memoria del radio para poder recuperarla más tarde.

## Antes de comenzar

- Debe haber un radio conectado.
- El panel del Navegador de memorias debe estar visible en el panel lateral de la Ventana principal.

## Pasos

1. Sintonice el slice activo a la frecuencia y el modo que desea guardar.
2. En el panel del Navegador de memorias, haga clic en **Add Memory**.

La frecuencia y el nombre del slice se guardan como una nueva entrada de memoria, que aparece inmediatamente en la tabla de memorias.

## Qué hace cada control

| Control | Comportamiento |
|---------|----------------|
| **Memory table** | Muestra cada memoria ordenada por frecuencia; un solo clic o Enter activa el slice sintonizado en esa memoria. Columnas: Frequency, Name. La memoria más cercana a la sintonización actual se resalta con un fondo distintivo. Un doble clic también sintoniza. |
| **Add Memory** | Guarda el slice actual como una nueva entrada de memoria. Se encuentra en la parte superior del panel, inmediatamente encima de las filas de la tabla de memorias. Información sobre herramientas: “Save the current slice on this panadapter as a memory.” |
| **No memories are available yet.** | Se muestra cuando el radio no tiene memorias cargadas. |

## Consejos

- La memoria se almacena en el propio radio, no localmente; el nombre y la frecuencia provienen de la configuración actual del slice activo.
- El botón **Add Memory** siempre está visible en la parte superior del panel, encima de la tabla de memorias con desplazamiento.
