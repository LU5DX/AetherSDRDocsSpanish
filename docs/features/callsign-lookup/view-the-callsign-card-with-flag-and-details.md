# Ver la tarjeta de indicativo con bandera y detalles

Consulte un indicativo de radioaficionado en QRZ.com para ver el nombre del operador, ubicación, cuadrícula geográfica, entidad DXCC, bandera del país, clase de licencia y biografía en una sola tarjeta de visualización.

## Antes de comenzar

- Se requiere una suscripción XML a QRZ.com para obtener datos completos, incluida la tarjeta de visualización con bandera, mapa y biografía
- **No** se necesita conexión con la radio: la consulta funciona sin conexión desde la radio

## Pasos

1. Abra **Tools > Callsign Lookup...**
2. Escriba el indicativo en el campo **Callsign**
3. Presione Enter o haga clic en **Lookup** para consultar QRZ.com y otras bases de datos configuradas
4. La **Callsign card** aparece mostrando el resultado: vea el nombre del operador, ubicación, entidad DXCC, bandera del país, cuadrícula geográfica, clase de licencia y biografía

## Función de cada control

| Control | Tipo | Comportamiento |
|---------|------|----------------|
| **Callsign field** | campo de texto | Ingrese un indicativo. Presione Enter o haga clic en Lookup para iniciar la consulta. |
| **Lookup button** | botón pulsador | Consulta QRZ.com y otras bases de datos configuradas para el indicativo ingresado. Requiere suscripción XML a QRZ.com para datos completos. |
| **Callsign card** | indicador | Muestra el resultado de la consulta: nombre del operador, ubicación, cuadrícula geográfica, entidad DXCC, bandera del país, clase de licencia y biografía. |
