# Ver el nombre del operador, ubicación y entidad DXCC

Consulte un indicativo y vea el nombre del operador, su ubicación, cuadrícula, entidad DXCC, bandera del país, clase de licencia y biografía, todo mostrado en una única tarjeta de indicativo.

## Antes de comenzar

- Necesita una conexión a internet activa para consultar bases de datos en línea.
- Para obtener datos completos (nombre, dirección, entidad DXCC), se requiere una suscripción XML válida a QRZ.com.

## Pasos

1. Abra el diálogo de Consulta de Indicativos mediante **Tools > Callsign Lookup...**
2. Escriba el indicativo que desea consultar en el campo **Callsign field**.
3. Presione **Enter** o haga clic en **Lookup** para realizar la consulta.
4. Lea los resultados en la **callsign card**, que muestra:
   - Nombre del operador
   - Ubicación (ciudad, estado/provincia, país)
   - Cuadrícula
   - Entidad DXCC
   - Bandera del país
   - Clase de licencia
   - Biografía (si está disponible)

## Función de cada control

| Control | Descripción |
|---|---|
| **Callsign field** | Campo de texto para ingresar un indicativo. Presione Enter o haga clic en Lookup para iniciar la consulta. |
| **Lookup button** | Envía la consulta a QRZ.com y otras bases de datos configuradas. Requiere suscripción XML a QRZ.com para obtener datos completos. |
| **Callsign card** | Muestra el resultado completo de la consulta: nombre, ubicación, cuadrícula, entidad DXCC, bandera del país, clase de licencia y biografía. |
