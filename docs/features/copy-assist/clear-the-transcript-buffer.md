# Limpiar el búfer de transcripción

Esta página explica cómo limpiar la transcripción acumulada de voz a texto en el panel Copy Assist, normalmente entre contactos o para empezar de nuevo.

## Antes de comenzar

- El panel Copy Assist debe estar abierto (View > Copy Assist, o pulse Ctrl+Shift+T).
- No es necesario que la transcripción esté activa para limpiar el búfer.

## Pasos

1. Abra el panel **Copy Assist**: **View > Copy Assist** (Ctrl+Shift+T).
2. Localice el botón **Clear** en la parte inferior del panel Copy Assist.
3. Haga clic en **Clear**. El campo de texto de la transcripción se vacía de inmediato.

## Consejos

- Limpiar no detiene la transcripción: el motor continúa escuchando y comenzará a llenar el búfer desde donde lo dejó.
- La limpieza es instantánea; no aparece ningún cuadro de diálogo de confirmación.

## Solución de problemas

- **El botón Clear no responde** — Si el panel Copy Assist no está visible, asegúrese de tenerlo abierto mediante **View > Copy Assist**. Si el botón aún no responde, intente cerrar y volver a abrir el panel.
