# Supervisar el nivel de pico posterior al ecualizador en el medidor del Output Fader

El Output Fader en el editor flotante de EQ muestra un medidor de nivel de pico en vivo posterior al EQ detrás de su manija, lo que le permite ver cuánto margen de sobrecarga queda después de aplicar su curva de ecualización y la configuración de ganancia maestra.

## Antes de comenzar

- El editor flotante de EQ debe estar abierto para la ruta que desea supervisar (TX o RX). El Output Fader no está presente en el mosaico del applet acoplado.
- La etapa de EQ debe estar habilitada. Si la etapa está en bypass, el medidor sigue reflejando la señal que pasa, pero la curva de EQ no tiene efecto.

## Pasos

1. Abra el editor flotante para la ruta que desea supervisar. Haga doble clic en la etapa de EQ correspondiente en el widget CHAIN — ya sea el lado TX o RX — para abrir el editor titulado "Aetherial Parametric EQ — TX" o "Aetherial Parametric EQ — RX".
2. Localice el Output Fader en el borde derecho del editor flotante. Es un fader combinado vertical con medidor de nivel.
3. Observe la barra de nivel detrás de la manija del fader. La barra muestra el nivel de pico posterior al EQ suavizado en tiempo real usando un degradado verde-ámbar-rojo, igual que el medidor de nivel del Tube.
4. Transmita o reciba audio como de costumbre. La barra de nivel se actualiza continuamente, reflejando el nivel de la señal después de que se hayan aplicado todas las bandas de EQ y el desplazamiento de ganancia maestra.

El medidor de nivel detrás de la manija del fader es solo un indicador. Muestra el pico posterior al EQ suavizado para la ruta vinculada a esta instancia del editor. No tiene un control separado ni una clave de persistencia.

## Consejos

- Si el medidor alcanza constantemente ámbar o rojo, arrastre la manija del Output Fader hacia abajo para reducir la ganancia posterior al EQ, o reduzca las ganancias de bandas individuales para bajar los niveles antes de la etapa maestra.
- Desplace la rueda del mouse sobre el Output Fader para realizar ajustes finos de 0,5 dB mientras observa el medidor.
- Haga doble clic en el Output Fader para restablecerlo a 0 dB sin alterar la configuración de sus bandas.
- Haga clic en la pantalla numérica en la parte inferior del fader para escribir un valor exacto en dB. El campo muestra un número simple cuando está enfocado; presione Enter o haga clic en otro lugar para confirmar. El valor se restringe al rango de −36,0 a +12,0 dB.
