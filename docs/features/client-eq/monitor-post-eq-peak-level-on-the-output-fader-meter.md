# Monitorizar el nivel máximo post-EQ en el medidor del fader de salida

El fader de salida en el editor EQ flotante muestra un medidor de nivel máximo post-EQ en vivo detrás de su control deslizante, lo que le permite ver cuánto margen de potencia queda después de aplicar su curva EQ y la configuración de ganancia maestra.

## Antes de comenzar

- El editor EQ flotante debe estar abierto para la ruta que desea monitorear (TX o RX). El fader de salida no está presente en el mosaico del applet acoplado.
- La etapa EQ debe estar habilitada. Si la etapa está desviada (bypassed), el medidor aún refleja la señal que pasa, pero la curva EQ no tiene efecto.

## Pasos

1. Abra el editor flotante para la ruta que desea monitorear. Haga doble clic en la etapa EQ correspondiente en el widget CHAIN — ya sea el lado TX o RX — para abrir el editor titulado "Aetherial Parametric EQ — TX" o "Aetherial Parametric EQ — RX".
2. Localice el fader de salida en el borde derecho del editor flotante. Es un control combinado vertical de fader y medidor de nivel.
3. Observe la barra de nivel detrás del control deslizante del fader. La barra muestra el nivel máximo post-EQ suavizado en tiempo real usando un degradado verde-ámbar-rojo, igual que el medidor de nivel del tubo.
4. Transmita o reciba audio de forma normal. La barra de nivel se actualiza continuamente, reflejando el nivel de la señal después de que se hayan aplicado todas las bandas EQ y el desplazamiento de ganancia maestra.

El medidor de nivel detrás del control deslizante del fader es solo un indicador. Muestra el pico post-EQ suavizado para la ruta vinculada a esta instancia del editor. No tiene un control separado ni una clave persistente.

## Consejos

- Si el medidor alcanza constantemente el ámbar o el rojo, arrastre el control deslizante del fader de salida hacia abajo para reducir la ganancia post-EQ, o reduzca las ganancias de bandas individuales para bajar los niveles antes de la etapa maestra.
- Desplace la rueda del ratón sobre el fader de salida para realizar ajustes finos de 0.5 dB mientras observa el medidor.
- Haga doble clic en el fader de salida para restablecerlo a 0 dB sin alterar la configuración de su banda.
- Haga clic en la pantalla numérica en la parte inferior del fader para escribir un valor exacto en dB. El campo muestra un número simple cuando está enfocado; presione Enter o haga clic en otro lugar para confirmar. El valor se limita al rango de −36.0 a +12.0 dB.
