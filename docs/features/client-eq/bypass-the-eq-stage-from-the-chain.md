# Ecualizador paramétrico etéreo (TX / RX)

El ecualizador paramétrico etéreo es un ecualizador del lado del cliente con dos copias independientes: **Aetherial TX EQ** y **Aetherial RX EQ**. Cada mosaico acoplado (mínimo 110 px de alto) muestra la respuesta del ecualizador sumada con una superposición de analizador FFT en vivo (incluida una traza de retención de picos). Toda la edición se realiza en la ventana flotante sin marco `ClientEqEditor` (titulada "Aetherial Parametric EQ — TX" o "— RX").

## Bypass de la etapa de ecualización en la cadena

Esta sección explica cómo omitir (bypass) el ecualizador paramétrico del lado del cliente para la ruta de audio TX o RX. El bypass elimina el ecualizador de la cadena de señal sin borrar la configuración de bandas.

### Antes de comenzar

- AetherSDR debe estar abierto. No se requiere conexión de radio para omitir el ecualizador.
- La etapa de ecualización ya debe estar presente en el widget CHAIN para la ruta que desea omitir (TX o RX).

### Pasos

1. Localice el widget CHAIN para la ruta que desea omitir: ya sea la cadena TX o la cadena RX.
2. Haga un solo clic en la etapa de ecualización en el widget CHAIN para esa ruta.

La etapa de ecualización ahora está omitida para esa ruta. El ajuste `ClientEqTxEnabled` o `ClientEqRxEnabled` se actualiza inmediatamente y se conserva entre reinicios.

Para volver a activar el ecualizador, haga un solo clic en la etapa de ecualización en el widget CHAIN nuevamente.

## Comportamiento de renderizado y caché

El lienzo del ecualizador utiliza una caché de renderizado de dos capas para mantener la visualización receptiva incluso mientras el analizador se actualiza a 25 Hz:

- **Capa de fondo** — contiene la cuadrícula, las etiquetas y las líneas guía de corte de filtro. Se vuelve a renderizar solo cuando cambian el tamaño del widget, la relación de píxeles del dispositivo, la fuente o los cortes de filtro de la radio.
- **Capa de respuesta** — contiene la respuesta del ecualizador sumada, la superposición de curva de referencia y los controles de banda. Se vuelve a renderizar cuando cambia el estado del ecualizador (bandas, familia de filtros, tasa de muestreo, estado habilitado, banda seleccionada o preset de referencia).
- **Analizador en vivo** — se dibuja directamente sobre las capas en caché cada fotograma, por lo que el relleno FFT y la traza de retención de picos se mantienen fluidos sin forzar el repintado completo del lienzo.

Esta caché es transparente para usted: no necesita configurar nada. Solo mantiene fluidos el desplazamiento y el redimensionamiento mientras ajusta las bandas.

## Rendimiento en pantallas grandes

Las capas de caché tienen límites para evitar un uso excesivo de memoria. Cada capa retenida está limitada a aproximadamente 32 MB de datos de píxeles. En lienzos muy grandes (por ejemplo, un editor de ecualizador maximizado en un monitor 4K o 5K con alta escala de visualización), las capas pueden exceder ese límite; en ese caso, el lienzo vuelve automáticamente al pintado directo para el fondo y la respuesta, lo que preserva la fidelidad visual completa a un pequeño costo de rendimiento. No necesita cambiar ningún ajuste: esta alternativa es automática y solo afecta a ventanas de editor inusualmente grandes.

## Presets de curva de referencia

La superposición de curva de referencia le ayuda a conformar su ecualizador hacia una respuesta objetivo conocida. Cada preset es una traza digitalizada de amplitud vs. frecuencia derivada de un micrófono clásico o un estándar de telecomunicaciones.

| Nombre del preset | Descripción                                                                                                                                                                                                             |
|-------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Off               | No se muestra ninguna superposición de referencia.                                                                                                                                                                      |
| AT&T 1959         | La "respuesta de frecuencia de transmisión óptima para voz" de AT&T de 1959: un objetivo canónico de pico de presencia de Bell Labs. Pico de +5 dB a 2.5 kHz, se atenúa por debajo de 300 Hz y por encima de 3.4 kHz. |
| Heil DX           | La recomendación publicada de Bob Heil para máxima potencia de habla en pile-ups. Pico más pronunciado de +6 dB a 2.7 kHz, corte de graves más agresivo que AT&T 1959.                                                |
| Astatic D-104     | La respuesta clásica del micrófono de cristal "lollipop": presencia extremadamente puntiaguda alrededor de 3 kHz (+10 dB) con atenuación profunda de graves.                                                           |
| Shure 444         | Respuesta clásica de micrófono de escritorio estilo transmisión: respuesta más amplia con realce de presencia más suave (+4 dB alrededor de 3 kHz).                                                                     |
| Heil HC-5         | Respuesta de elemento de micrófono dinámico SSB moderno: el realce de presencia media tiene un pico alrededor de 3 kHz a +5 dB.                                                                                         |
