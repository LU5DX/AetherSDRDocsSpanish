# Restablecer todas las bandas del ecualizador a la plantilla predeterminada de 10 bandas

Utilice este procedimiento para descartar todas las modificaciones de bandas del ecualizador de TX o RX y devolverlo a la configuración de fábrica de 10 bandas. Esto también restablece el número de bandas y la familia de filtros a sus valores predeterminados.

## Antes de comenzar

- El editor flotante de la ruta del ecualizador que desea restablecer (TX o RX) debe estar abierto. Consulte [Open the frameless editor to add / remove / tune bands on either side](open-the-frameless-editor-to-add-remove-tune-bands-on-either-side.md) si aún no lo está.

## Pasos

1. En la barra de título del editor flotante, confirme que está en la ruta correcta; el título de la ventana muestra "Aetherial Parametric EQ — TX" o "Aetherial Parametric EQ — RX".
2. Haga clic en **Reset** en la franja del encabezado del editor.

Todas las bandas se reemplazan inmediatamente con la plantilla predeterminada de 10 bandas. El número de bandas se restaura a 10 y el combo Filter family se restablece a Butterworth. La configuración se guarda de inmediato.

## Consejos

- Reset afecta solo a la ruta que se muestra en la ventana del editor actual. Para restablecer la otra ruta, abra el otro editor y repita el proceso.
- El Output Fader (ganancia maestra posterior al ecualizador, conservada como `ClientEqTxMasterGain` o `ClientEqRxMasterGain`) no se modifica con Reset. Haga doble clic en el fader para devolverlo a 0 dB por separado si es necesario.
- Para escribir un valor preciso del Output Fader, haga clic en la lectura en dB en la parte inferior del fader; aparece un campo de texto. Escriba cualquier valor de -36.0 a +12.0 dB y presione Enter para confirmar. El campo también acepta separadores decimales localizados. Presione Escape para cancelar la edición y volver al valor anterior.
- La superposición de curva de referencia (seleccionable desde la franja del encabezado del editor) no se modifica con Reset. Para eliminarla, configure el combo Reference curve en Off.
