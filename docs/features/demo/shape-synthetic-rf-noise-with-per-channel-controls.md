# Dé forma al ruido RF sintético con controles por canal

Dé forma al entorno RF simulado cuando utiliza la radio Demo incorporada, activando o desactivando fuentes de ruido individuales y ajustando sus niveles.

## Antes de comenzar

- Conéctese a la radio Demo incorporada desde el diálogo **Settings > Connect to Radio...** o desde el panel Connect

## Pasos

1. Abra el applet de Demo Mode desde la bandeja del Applet Panel (el botón DEMO en la bandeja aparece solo cuando la radio Demo está conectada).
2. En el applet, localice la sección **Noise channel toggles**. Cada casilla de verificación controla una fuente de ruido independiente: ruido rosa, ruido blanco, ráfagas de QRM, birdies y otras.
3. Marque una casilla para activar esa fuente de ruido; desmárquela para desactivarla.
4. Para cada fuente de ruido activada, ajuste su **Noise level slider** para definir la intensidad.
5. Opcionalmente, haga clic en un botón **Scene presets** para configurar todos los canales a la vez según un escenario específico (tormenta, noche-40m, pileup de concurso, banda silenciosa, etc.).

## Qué hace cada control

| Control | Acción |
|---------|--------|
| Noise channel toggles (casillas de verificación) | Activan o desactivan fuentes de ruido individuales. Fuentes disponibles: ruido rosa, ruido blanco, ráfagas de QRM, birdies y otras. |
| Noise level sliders (deslizadores de nivel) | Ajustan el nivel de cada fuente de ruido activada de forma independiente. |
| Scene presets (botones de preajustes) | Aplican una combinación preconfigurada de canales y niveles de ruido para simular una condición de banda específica. |

## Consejos

- Comience con todas las fuentes de ruido desactivadas (todas las casillas desmarcadas) para escuchar la simulación más limpia, luego active las fuentes una por una para comprender su carácter.
- Utilice los preajustes de escena como punto de partida rápido, luego ajuste finamente los deslizadores individuales.
