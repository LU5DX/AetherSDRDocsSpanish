# Conozca las diferencias entre NR2, NR4, DFNR y MNR

Esta página explica cómo abrir la guía de cancelación de ruido incluida en AetherSDR, la cual describe las diferencias entre los modos de reducción de ruido NR2, NR4, DFNR y MNR disponibles en la FLEX-8600.

## Antes de comenzar

- No se requiere conexión a la radio para leer este tema de ayuda.
- AetherSDR debe estar instalado con sus recursos de ayuda incluidos intactos.

## Pasos

1. Haga clic en `Help > Understanding Noise Cancellation...` en la barra de menú.
2. Se abre HelpDialog con el título configurado para el tema de cancelación de ruido. El diálogo utiliza estilo temático a través de ThemeManager, adaptándose al tema actual de la aplicación.
3. Lea el contenido en el visor de Markdown. El tema cubre las diferencias entre NR2, NR4, DFNR y MNR.
4. Para buscar dentro del tema, escriba un término en el campo Find y haga clic en Next o Previous para recorrer las coincidencias. Presione Return para buscar la siguiente coincidencia; presione Shift+Return para buscar la coincidencia anterior.
5. Haga clic en Close cuando termine.

## Diseño de HelpDialog

HelpDialog muestra las siguientes secciones:

- **AETHERSDR OFFLINE HELP** – Encabezado de marca mostrado sobre el título.
- **Title** – Muestra el título de la ventana (nombre del tema).
- **Subtitle** – Descripción del tema en una línea: "La ayuda incluida está disponible incluso cuando su computadora de estación está desconectada."
- **Find row** – Contiene una etiqueta Find, un campo de texto de búsqueda, botones Next y Previous, y un indicador de estado.
- **Visor de Markdown** – Renderiza el recurso Markdown cargado con estilo temático.
- **Hint/footer** – Muestra el consejo: "Consejo: El menú Help mantiene cada guía separada para que pueda reabrir solo el tema que necesita."
- **Botón Close** – Cierra el diálogo.

## Consejos

- El borde del campo Find se vuelve rojo cuando no hay coincidencias para su término de búsqueda. Borre el campo o revise su término e intente nuevamente.
- Si el archivo de ayuda no se carga, AetherSDR muestra un mensaje en el visor. Reinstale la aplicación para restaurar los recursos de ayuda faltantes.
- Cada tema de ayuda en el menú Help está separado. Puede reabrir solo este tema en cualquier momento sin tener que navegar lejos de otras guías.
- La apariencia del diálogo sigue el tema activo de la aplicación. Los colores se ajustan dinámicamente según la configuración del tema.
- Abrir múltiples guías de ayuda simultáneamente ahora conserva sus posiciones de ventana individuales. Cada guía recuerda su propio tamaño y ubicación, evitando que se superpongan entre sí.
