# Cambie rápidamente entre perfiles de transmisión

Cambie entre perfiles de transmisión guardados usando el applet Profile Switcher, útil cuando cambia de banda, modo o condiciones de operación sin necesidad de abrir el cuadro de diálogo completo del Profile Manager.

## Antes de comenzar

- La radio debe estar conectada.
- Debe tener al menos un perfil de transmisión guardado (cree uno en `Profiles > Profile Manager...`).

## Pasos

1. Abra el **Applet panel** y localice el mosaico **Profile Switcher**.
2. Haga clic en el botón **Next profile** para avanzar al siguiente perfil en la lista, o haga clic en el botón **Previous profile** para retroceder.
   - La pantalla se actualiza para mostrar el nombre del perfil recién activado.
3. Para saltar directamente a un perfil específico sin recorrerlos:
   - Haga clic en el botón **Profile menu**.
   - Seleccione el perfil deseado de la lista desplegable.

## Función de cada control

| Control | Comportamiento |
|---------|----------------|
| Nombre del perfil actual | Muestra el nombre del perfil de transmisión activo actualmente. |
| Previous / Next profile | Avanza o retrocede cíclicamente por la lista de perfiles guardados. |
| Profile menu | Abre un menú desplegable para seleccionar directamente cualquier perfil guardado. |
