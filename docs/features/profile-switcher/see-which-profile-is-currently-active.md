# Ver qué perfil está activo actualmente

El applet del Selector de Perfiles muestra el nombre del perfil de transmisión activo, para que siempre sepa qué micrófono, procesador, ecualizador y filtros están en uso.

## Antes de empezar

- La radio debe estar conectada.
- Debe existir al menos un perfil de transmisión (guardado mediante **Profiles > Profile Manager...**).

## Pasos

1. Abra la bandeja del Panel de Applets (parte inferior de la ventana de AetherSDR).
2. Localice el mosaico **Profile Switcher** (etiquetado **PSW**).
3. Lea el nombre del perfil que aparece en el mosaico: este es el perfil de transmisión activo actualmente.

## Función de cada control

| Control | Funcionamiento |
|---|---|
| Nombre del perfil actual (indicador) | Muestra el nombre del perfil de transmisión activo. |
| Botones Anterior / Siguiente | Alternan al perfil de transmisión anterior o siguiente de la lista. |
| Botón de menú del perfil | Abre un menú desplegable para saltar directamente a cualquier perfil guardado. |
