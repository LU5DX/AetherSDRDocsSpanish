# Editar o eliminar una red programada

Modifique el nombre, frecuencia, modo, regla de recurrencia o recordatorio de una red existente, o elimine una red por completo de su programación.

## Antes de empezar

- El diálogo Net Scheduler debe estar abierto (`Tools > Net Scheduler...`).
- Debe existir al menos una red en la tabla de redes.

## Pasos

1. En la tabla de redes, haga clic en la fila de la red que desea editar o eliminar para seleccionarla.
2. Haga clic en **Edit / Delete**.
3. Para editar, realice los cambios en el diálogo del editor de redes y luego confirme.
   Para eliminar, seleccione la opción de eliminación en el diálogo.

## Función de cada control

| Control | Comportamiento |
|---|---|
| Net table | Lista de todas las redes programadas. Haga clic en una fila para seleccionarla antes de usar Edit, Delete, Tune Now o Import/Export. |
| Edit / Delete | Abre un diálogo para la red seleccionada. Puede cambiar el nombre, frecuencia, modo, regla de recurrencia y recordatorio de la red. También puede eliminar la red de la programación por completo. |
| Recurrence rule | Frecuencia con la que se repite la red. Valor predeterminado: **Weekly**. Opciones: Once, Daily, Weekly, Biweekly, Monthly. |
| Reminder | Minutos antes del inicio de la red para mostrar un banner en el panadapter. Valor predeterminado: **5 min**. Rango: **1–60 min**. |
