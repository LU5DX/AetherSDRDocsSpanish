# Sintonizar la radio a una memoria almacenada

Abra el diálogo Memory Channels para encontrar una frecuencia almacenada y enviarla directamente al slice receptor activo.

## Antes de comenzar

- AetherSDR debe estar conectado a una radio FLEX-8600. El diálogo Memory Channels requiere una conexión activa con la radio.
- Debe haber al menos una memoria almacenada. Consulte [Add a memory at current frequency](add-a-memory-at-current-frequency.md) si no tiene ninguna.

## Pasos

1. Haga clic en `Settings > Memory...` para abrir el diálogo Memory Channels.
2. Localice la memoria que desea. Use el campo `Search:` para filtrar por nombre, o use el cuadro combinado `Profile:` para acotar la lista por perfil.
3. Haga clic en la fila de la tabla de memorias para seleccionarla.
4. Haga clic en `Tune`.

El slice activo se sintoniza a la frecuencia, el modo y los ajustes de filtro almacenados en esa memoria.

**Atajo:** Haga doble clic en cualquier fila de la tabla de memorias para sintonizar de inmediato sin hacer clic en `Tune`.

## Consejos

- Si no puede ver la memoria que desea, verifique si `Profile:` está configurado con un filtro que la excluya. Configure `Profile:` para mostrar todas las entradas.
- En Linux y Windows, mantenga presionado Ctrl y haga clic para seleccionar filas individuales sin deseleccionar las demás. En macOS, use Command-clic. Solo se usa la primera memoria seleccionada cuando hace clic en `Tune`.
- Use el botón `Add` o Ctrl+N para almacenar rápidamente la frecuencia actual del slice como una nueva memoria.
- Use los botones `Import...` y `Export...` para transferir memorias entre radios o compartirlas con otros operadores.
- El diálogo recuerda su posición y tamaño entre sesiones: no es necesario reposicionarlo cada vez que lo abre.
- Al editar campos restringidos (Mode, Step, Tone Mode, etc.), la lista del cuadro combinado se abre de inmediato para que pueda elegir un valor con un solo clic. Para los campos editables, también puede escribir un valor personalizado y el diálogo validará su entrada.

## Solución de problemas

- **`Tune` no tiene efecto o está deshabilitado** — Confirme que hay una sola fila seleccionada en la tabla de memorias y que AetherSDR está conectado a la radio.
- **La memoria que desea no aparece en la tabla** — El filtro `Search:` o `Profile:` puede estar ocultándola. Vacíe el campo `Search:` y configure `Profile:` para mostrar todas las entradas.
- **No se puede agregar una memoria** — Asegúrese de que la radio esté conectada y de que haya un slice activo disponible.
- **La posición del diálogo se restablece inesperadamente** — La geometría se guarda al cerrar el diálogo. Si otra ventana o la configuración de pantalla cambió, la posición guardada puede ser inválida. Reposicione y cierre el diálogo para guardar la nueva ubicación.
- **La zona de redimensión se siente diferente en el borde superior** — La zona de redimensión del borde superior comienza justo debajo del área de arrastre de la barra de título (12 px), lo que garantiza que la barra de título siga siendo fácil de agarrar para mover el diálogo sin activar accidentalmente una redimensión.
