# Sintonizar la Radio a una Memoria Almacenada

Abra el cuadro de diálogo Canales de memoria para encontrar una frecuencia almacenada y enviarla directamente al receptor de slice activo.

## Antes de comenzar

- AetherSDR debe estar conectado a una radio FLEX-8600. El cuadro de diálogo Canales de memoria requiere una conexión activa con la radio.
- Al menos una memoria debe estar ya almacenada. Consulte [Añadir una memoria en la frecuencia actual](add-a-memory-at-current-frequency.md) si no tiene ninguna.

## Pasos

1. Haga clic en `Settings > Memory...` para abrir el cuadro de diálogo Canales de memoria.
2. Localice la memoria que desea. Utilice el campo `Search:` para filtrar por nombre, o use el cuadro combinado `Profile:` para restringir la lista por perfil.
3. Haga clic en la fila de la tabla de memorias para seleccionarla.
4. Haga clic en `Tune`.

El slice activo se sintoniza a la frecuencia, el modo y la configuración de filtro almacenados en esa memoria.

**Atajo:** Haga doble clic en cualquier fila de la tabla de memorias para sintonizar inmediatamente sin hacer clic en `Tune`.

## Consejos

- Si no puede ver la memoria que desea, verifique si `Profile:` está configurado con un filtro que la excluye. Configure `Profile:` para mostrar todas las entradas.
- En Linux y Windows, mantenga presionada la tecla Ctrl y haga clic para seleccionar filas individuales sin anular la selección de otras. En macOS, use Comando-clic. Solo la primera memoria seleccionada se utiliza cuando hace clic en `Tune`.
- Use el botón `Add` o Ctrl+N para almacenar rápidamente la frecuencia actual del slice como una nueva memoria.
- Use los botones `Import...` y `Export...` para transferir memorias entre radios o compartirlas con otros operadores.
- El cuadro de diálogo recuerda su posición y tamaño entre sesiones — no es necesario reposicionarlo cada vez que lo abre.
- Al editar campos restringidos (Modo, Paso, Modo de tono, etc.), la lista del cuadro combinado se abre inmediatamente para que pueda elegir un valor con un solo clic. Para los campos editables, también puede escribir un valor personalizado y el diálogo validará su entrada.

## Solución de problemas

- **`Tune` no tiene efecto o está deshabilitado** — Confirme que una sola fila está seleccionada en la tabla de memorias y que AetherSDR está conectado a la radio.
- **La memoria que desea no aparece en la tabla** — El filtro `Search:` o `Profile:` puede estar ocultándola. Limpie el campo `Search:` y configure `Profile:` para mostrar todas las entradas.
- **No se puede añadir una memoria** — Asegúrese de que la radio está conectada y hay un slice activo disponible.
- **La posición del diálogo se restablece inesperadamente** — La geometría se guarda cuando cierra el cuadro de diálogo. Si otra ventana o la configuración de la pantalla cambió, la posición guardada puede no ser válida. Reposicione y cierre el cuadro de diálogo para guardar la nueva ubicación.
- **La zona de redimensionamiento se siente diferente en el borde superior** — La zona de redimensionamiento del borde superior comienza justo debajo del área de arrastrar para mover de la barra de título (12 px), asegurando que la barra de título siga siendo fácil de agarrar para mover el diálogo sin activar accidentalmente un redimensionamiento.
