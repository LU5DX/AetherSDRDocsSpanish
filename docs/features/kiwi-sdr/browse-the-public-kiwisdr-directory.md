# Explorar el directorio público de KiwiSDR

Abra el applet de KiwiSDR para buscar y explorar el directorio público de receptores KiwiSDR disponibles en todo el mundo, con detalles sobre el nombre, la ubicación, la banda y el estado de cada receptor.

## Antes de empezar

- AetherSDR debe estar en ejecución (no se requiere conexión de radio)

## Pasos

1. Abra el panel de Applets (si no está visible aún).
2. Haga clic en el mosaico **KiwiSDR** para abrir el applet.
3. En la **Receiver list**, escriba un término de búsqueda (por ejemplo, una ubicación o banda) para filtrar el directorio.
4. Explore la lista de receptores disponibles que muestra su nombre, ubicación, banda y estado de conexión.

## Descripción de cada control

| Control | Descripción |
|---------|-------------|
| **Receiver list** | Lista desplazable y con búsqueda de receptores KiwiSDR públicos, con nombre, ubicación, banda y estado. |
| **Assign to slice** | Asigna el receptor KiwiSDR seleccionado al slice activo para sintonización y escucha. |
| **Status indicator** | Muestra el estado de la conexión (Disconnected / Connecting / Connected / Error) con texto de detalle. Valor predeterminado: Disconnected. |

## Consejos

- El directorio se actualiza al abrir el applet, mostrando los receptores actualmente en línea.
- Use el campo de búsqueda para encontrar rápidamente receptores en una región o banda específica.
