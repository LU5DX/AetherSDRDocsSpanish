# Copiar dirección MAC, versión de firmware o información de licencia al portapapeles

Copie la dirección MAC, la versión de firmware, los detalles de suscripción de licencia u otros identificadores de solo lectura de una radio al portapapeles del sistema para compartirlos con el soporte técnico o para documentación.

## Antes de comenzar

- AetherSDR debe estar conectado a la radio.
- Abra Radio Setup (`Settings > Radio Setup...`).

## Pasos

1. Haga clic en la pestaña **Radio**.
2. Localice el valor que desea copiar:
   - **MAC Address** — en la pestaña **Network**, busque **MAC Address**.
   - **Firmware version** — en la pestaña **Radio**, vea **HW Version**.
   - **License Info** — en la pestaña **Radio**, vea **Subscription**, **Expiration**, **Radio ID** o **Licensed version**.
   - **Radio SN**, **Model**, **Options**, **IP Address**, **Mask** — cada uno tiene un botón de copia.
3. Haga clic en el icono de portapapeles (dos rectángulos superpuestos) junto al valor. Aparece brevemente un mensaje emergente "Copied".
